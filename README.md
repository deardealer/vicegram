# VICEGRAM — GitHub Pages preview

Static prototype with 10 screens.

## Publish
1. Create a public GitHub repository (for example `vicegram`).
2. Upload **the contents of this ZIP** to the repository root (index.html, screen_01.html … screen_10.html, assets/). Do not upload the ZIP itself.
3. In repository Settings → Pages → Build and deployment choose Deploy from a branch, branch `main`, folder `/(root)`; Save.
4. Open the URL shown under Pages.

This is a static demo: posts, likes and comments are browser-local, not shared between devices. GitHub Pages is not a backend.
